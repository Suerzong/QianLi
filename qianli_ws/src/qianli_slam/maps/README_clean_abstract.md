# Clean abstract structural map v0.2

This is the first output intended to look like a model rather than a processed
photograph. It keeps long neutral horizontal/vertical wall strokes and a clean
outer envelope, while removing the original colours, evacuation arrows, fire
symbols, most text, and the large lecture-hall seating patterns.

Files:

- `qianli_bupt_shahe_public_teaching_floor1_clean_abstract_v0_2.pgm/.yaml` —
  ROS 2 trinary map, `0.020 m/px`, provisional extent `44.4 m × 35.9 m`.
- `qianli_bupt_shahe_public_teaching_floor1_clean_abstract_v0_2.png` — review image
  with the QianLi footprint at the provisional map origin.
- `qianli_bupt_shahe_public_teaching_floor1_clean_abstract_v0_2.sdf` — matching
  approximate Gazebo wall world generated from the cleaned raster.

The structure is still automatically extracted from a perspective photo. Door
openings, diagonal walls, exact room dimensions and the true survey coordinate
system remain to be manually traced and measured.
