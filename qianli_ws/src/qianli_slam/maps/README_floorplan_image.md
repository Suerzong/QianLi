## 比例和建模状态

门洞 `1.20 m` 当前按约 `120 px` 标定，得到 `100 px/m`；照片存在透视和局部反光，
所以这是“可测试的初版比例”，不是测量成果。后续必须用多个门洞/走廊宽度做一致性
检查，再把主要墙线矢量化成 Gazebo 碰撞盒和生产用 Nav2 OccupancyGrid。

第一版建模将分成：

1. 结构层：外墙、主要内墙、走廊、楼梯/电梯核心；
2. 通行层：门洞、不可通行墙体、允许机器人入口；
3. 场景层：报告厅座椅、固定柜体和其他可识别障碍；
4. 导航层：真实底盘八边形 footprint、门宽/走廊净宽检查、测试目标点。

绿色疏散箭头和红色消防图标不会直接变成墙体或障碍物。
