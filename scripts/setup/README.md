# scripts/setup — 环境安装脚本

| 脚本 | 用途 | 适用环境 |
|---|---|---|
| install_ros2_humble.sh | 安装 ROS 2 Humble 基础环境（含 colcon / rosdep） | 目标 Ubuntu 22.04 主机 |
| source_env.sh | 加载 ROS 2 与 QianLi 工作区环境 | Ubuntu 22.04 |

> 当前开发机为 Windows 11，这些脚本仅在目标 Ubuntu 22.04 环境执行（详见 [ENVIRONMENT.md](../../docs/ENVIRONMENT.md)）。
