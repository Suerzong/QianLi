# 灰色物块抓取链路排查 — 2026-10-05

本轮按用户要求先修复、验证仿真，并对真机链路做代码、相机回放及舵机寄存器只读检查。没有发送运动目标、使能或扭矩写入指令。用户确认：灰色物块按边长20mm立方体处理，棋盘单格33mm，相机/棋盘未移动，机械臂电源已开启。

## 敲桌子的直接证据

1. **真机与快照脚本四元数错误。** 原来 yaw=-90° 时工具Z指向基座-X，夹爪横着。已改为 `Rz(yaw) @ Rx(pi)` 的正确ROS四元数，5个偏航角、3个入口均验证工具Z朝下。
2. **IK精修丢弃姿态。** 真机DLS仅优化XYZ；仿真DLS姿态权重默认0。离线重放当前相机目标，旧真机IK位置误差仅0.039mm，但工具倾斜26.37°；张开夹爪最低点在假定棋盘面以下14.59mm。这是网格几何复现，不是实测真机撞击距离。
3. **仅限制TCP高度不足以限制爪尖。** 工具倾斜时，即使TCP高于棋盘，指尖仍可能进入棋盘。现同时约束工具轴并拒绝超差目标；真实棋盘面和TCP偏置仍需实测。

修复后的真机IK同时检查位置≤3mm、工具轴≤5°。约303mm半径的近目标可达；约342mm半径目标位置误差超过3mm，拒绝；当前图像对应的约396mm抓取目标位置、姿态均超差，拒绝。拒绝后的求解结果不会写入运动目标。5°只是新增的拒绝阈值，不构成所有关节轨迹的碰撞证明。

## 仿真修复后的验证

原先39/40成功率对应旧棋盘、未严格约束工具轴的模型，不能作为本轮真机姿态的验收依据。纠正棋盘尺寸后原流程37/40；加入工具轴约束后原来的高空接近/直线上提目标不可达，已改用棋盘内可达位置及分段轨迹。

最终流程：物块棋盘坐标 `(60,-15)mm`；TCP相对中心偏移 `(12,-4,+2)mm`；张开1.0rad、闭合-0.08rad。先在向基座收回的高位接近，经过物块上方25mm后下降；闭合后检查双侧接触，先竖直抬离25mm，再向基座收回并上提100mm。每步用真实仿真反馈补偿最多3次静态跟踪误差，通过限速ctrl执行，不改动运行中的qpos。

候选重试偏移为 `(12,-4,2)`、`(12,-4,4)`、`(14,-6,4)mm`；每次保留物理状态，张开、落稳后读取物块实际位置并加同一观测误差。发生IK/运动超差停止；闭合后没有双侧接触，不进行上提。

标准重复3/3通过，最低持稳升高约100.56mm；双侧接触100%，TCP阶段误差最大约0.52mm，阶段工具轴最大偏差约1.66°，环境穿透0mm。开发样本seed=20261005为34/40：4次无双侧夹持、2次重试时IK不可达。冻结参数后的独立样本seed=20261006为31/40：8次无双侧夹持、1次重试时IK不可达，均记为失败。因此固定偏移方案尚未通过可靠抓取验收；本轮完成了标准场景修复及失败原因分离，不宣称自动抓取已经稳定。完整汇总见[最新仿真验收](GRASP_SIM_VALIDATION.md)。

模型仍使用URDF关节限位；真实驱动限位另在离线IK回归中验证。这不等同于整个物理仿真已经覆盖真机原始计数限位、实际增益和夹持力。质量8g、摩擦系数1、臂力矩3N·m、夹爪1.5N·m均为模型假设；臂自碰撞和前臂与物块接触未建模。
